# ROADMAP DE IMPLEMENTAÇÃO — DIRETORIA

**Documento:** Roadmap V0.1

O roadmap organiza o trabalho em incrementos verificáveis. Não representa promessa de data; representa dependência lógica.

# Incremento 0 — Fundação

Entregas:

- repositório;
- docs canônicos;
- ambientes;
- CI;
- banco/migrations;
- secrets;
- observabilidade;
- identidade mínima;
- RBAC/auditoria.

Saída:

`HML operacional e seguro para começar domínio.`

# Incremento 1 — Núcleo econômico

Entregas:

- edição;
- configuração financeira;
- custos;
- receitas garantidas;
- pagamentos mock/sandbox;
- créditos;
- motor de quórum;
- snapshots;
- reembolso;
- GO/NO-GO.

Teste-chave:

`400 → não viável; 641 → viável; reembolso → recálculo; confirmação bloqueada/permitida corretamente.`

Saída:

`Tese econômica comprovada em HML.`
